# CryoCast notebooks

The notebooks in this directory are supplementary examples and research artifacts for CryoCast. They are not required to use the package.

See the [Notebooks page](https://alan-turing-institute.github.io/cryocast/user-guide/notebooks/) of the documentation for setup instructions, the recommended order, and each notebook's prerequisites.

Start with [`demo_pipeline.ipynb`](demo_pipeline.ipynb).
